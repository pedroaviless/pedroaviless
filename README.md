## 🚀 Proyectos destacados

### 🎾 [PistaGO](https://github.com/pedroaviless/PistaGO) — Sistema de reserva de pistas de tenis
Proyecto final de grado. Backend en **Kotlin + Spring Boot 3.5** desplegado en VPS propio, cliente Android con **Jetpack Compose**, arquitectura MVVM/Clean, autenticación JWT, notificaciones FCM y lista de espera automatizada.

`Kotlin` `Spring Boot` `Jetpack Compose` `PostgreSQL` `JWT` `FCM` `DigitalOcean` `Nginx`

---

### 📊 Pulse — Dashboard de inteligencia de ciberseguridad *(Constella Intelligence)*
Dashboard operacional interno construido durante la FCT. Upload de CSV, KPIs, gráficos de Infostealers/Breaches, comparador de snapshots y página de tendencias con agrupación temporal.

`Next.js 15` `TypeScript` `Tailwind CSS` `Recharts` `shadcn/ui`

---

### 🏆 Transfermarkt Analytics — Pipeline de Data Engineering *(Cívica)*
Pipeline completo de datos de fútbol sobre arquitectura Medallion (Bronze → Silver → Gold). SCD-2, modelos incrementales, 124 tests en verde en DEV y PROD.

`dbt Cloud` `Snowflake` `Power BI` `SQL` `Kimball` `SCD-2`
